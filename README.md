### Решатели 
В данном репозитории добавлено три решателя (в папке gpt_solvers):
1. self_cons_fixed_N_xf_pM - решение уравнений СС относительно переменных $x_f$, $M_1$ и $M_2$. На выходе - набор решений в виде [x_f, M_1, M_2], где $M_1,M_2\geq0$, $x_f=\varepsilon_F/\Gamma$ - уравнения решаются относительно x_f, зависимость от $x$ восстанавливается вручную, где необходимо.
2. self_cons_bounded_posM - решение уравнений СС относительно переменных $N_1$, $M_1$, $N_2$ и $M_2$. На выходе - набор решений в виде [N_1, M_1, N_2, M_2], где $M_1,M_2\geq0$.
3. self_cons_bounded - решение уравнений СС относительно переменных $N_1$, $M_1$, $N_2$ и $M_2$. На выходе - набор решений в виде [N_1, M_1, N_2, M_2], где $M_1$, $M_2$ могут быть любого знака.

### Энергии
Энергии находятся для двух канонических ансамблей:
1. up_limit_of_energy_of_state - для БКА функция вычисляет верхний предел интегрирования формулы $$\dfrac{\Omega(N,M)}{\Gamma} = \dfrac{1}{\Gamma}\sum_{i=1}^2\left[ \int\limits_{-\infty}^{\varepsilon_F} (\omega-\varepsilon_F)\rho_i(\omega)d\omega - \dfrac{U}{4}\left(N_i^2-M_i^2\right)\right]$$
2. up_limit_of_energy_E_of_state - для КА функция вычисляет верхний предел интегрирования формулы $$\dfrac{E(x,M)}{\Gamma} = \dfrac{\Omega(x,M;N_{1,2}=\text{fixed})}{\Gamma}-x_F(N_1+N_2)$$


Начало отсчета (немагнитное решение) при необходимости учитывается вручную.

### energy_surfaces.py
В данном .py файле реализовано построение энергетических поверхностей по описанным выше формулам для КА и БКА. Четырехмерная поверхность редуцирована до двухмерной поверхности условием $N_1=N_2$ и $M_1=M_2$. Для отображения точек СС-решений используются все три решателя, какой будет предпочтительнее.

Если необходимо изменить масштаб отстраиваемой поверхности, меняйте диапазоны значений x_values, N_values, M_values (в коде указывается комментарием "Сетка для построения поверхности").
